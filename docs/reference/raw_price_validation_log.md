# Raw-Price Validation Log

Accumulating evidence base for the open question in Section 5 of the engagement tuning spec: does presenting raw dollar figures in concept stimulus (isolated from marketing-register copy) hold ranking correlation, or does it penalize high-price concepts disproportionately vs. real category norms?

**Prior data point (pre-log):** One image+text pilot showed the highest-priced concept in that run (a $148 shirt) dropped most sharply when raw price was introduced, AND that same run broke concept ranking overall (ρ = −0.10). But that run also introduced marketing-dense text simultaneously — price and marketing-register effects were not isolated. Every engagement using raw price is a live data point on the isolated question.

---

## How to fill this in

After each engagement that uses raw price figures in stimulus, add a row. Skip engagements that don't include raw price.

Columns:
- **Engagement** — folder name.
- **Category** — supplement, apparel, beverage, etc.
- **Price range** — cheapest → most expensive concept.
- **Ranking held?** — yes / no / unclear / no baseline. If a real-world ranking or prior expectation exists, did SSR reproduce it? "No baseline" = fine, still log; the negative case is just less informative.
- **High-price concept behavior** — did the most-expensive concept underperform proportionally to category norms, or disproportionately? Cite the mean PI delta if numeric.
- **Marketing-register isolation** — was price presented cleanly (spec-sheet register, no marketing adjectives)? If not, this data point is confounded and can't isolate the price question.
- **Notes** — anything relevant to the accumulating picture.
